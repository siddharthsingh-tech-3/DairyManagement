# API

Interactive docs are generated by FastAPI and always reflect the current
code — don't hand-maintain a duplicate spec:

- Swagger UI: `GET /docs`
- ReDoc: `GET /redoc`
- Raw OpenAPI schema: `GET /openapi.json` (importable directly into Postman:
  *Import → Link* and paste the URL, or *Import → File* after saving it).

All routes are mounted under `API_V1_PREFIX` (default `/api/v1`).

## Conventions

- **Response envelope**: every response is `{"success": bool, "message": str, "data": <payload|null>}`.
  Validation errors additionally include an `"errors"` array (Pydantic's
  `.errors()` shape).
- **Auth**: `Authorization: Bearer <access_token>`. Get one from
  `POST /auth/login`; refresh via `POST /auth/refresh` with the refresh token
  (rotates it — the old one is revoked). `POST /auth/logout` revokes a refresh
  token.
- **RBAC**: `super_admin` bypasses all permission checks. `vendor`/`driver`
  routes are gated by `GET /permissions` (the live matrix, admin-editable via
  `PUT /permissions` or `POST /permissions/{feature}/{role}/cycle`).
- **List endpoints**: return a plain array in `data` (pagination/search/sort
  is handled client-side by the shared `DataTable` component for these
  moderate-sized datasets; `core/responses.py::Page`/`PageParams` are
  available for any endpoint that later needs server-side paging).

## Endpoint groups

| Prefix | Module | Key operations |
|---|---|---|
| `/auth` | Authentication | login, refresh, logout, forgot/reset/change-password, `me` |
| `/users` | User management | list, create, update (admin only) |
| `/permissions` | RBAC matrix | get matrix, update level, cycle level (admin only) |
| `/vendors` | Vendors & ledger | CRUD, detail (+ledger), collect outstanding, send reminder |
| `/products` | Products & stock | CRUD, stock movements, reorder |
| `/orders` | Demand scheduling | create (cutoff/credit-limit rules applied), list (vendor-scoped), update, cancel |
| `/deliveries` | Dispatch & delivery | list (role-scoped), dispatch, mark delivered, confirm receipt, request extra items |
| `/drivers` | Truck/driver roster | list, create (admin only) |
| `/crates` | Crate ledger | summary, transactions, reconcile, disputes (create/resolve) |
| `/billing` | Invoices & payments | list/generate/get invoices, pay/remind, record/list payments |
| `/expenses` | Operating expenses | list (date range), create |
| `/reports` | Dashboards & reports | role-aware dashboard, profit & loss, operational metrics, audit log |
| `/settings` | Business settings | list/upsert key-value config (admin only) |

## Postman

Import `GET /openapi.json` as described above — it produces a full collection
with every route, request schema, and example already typed from the Pydantic
models, and stays in sync automatically as the API evolves.
